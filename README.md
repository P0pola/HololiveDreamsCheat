# HololiveDreamsCheat

A lightweight utility for [*Hololive Dreams* on Steam](https://store.steampowered.com/app/4282500), featuring automated rhythm gameplay and character movement speed customization.

---

## Installation

1. Navigate to the **[Releases](../../releases)** section of this repository.
2. Download the latest archive (e.g., `HololiveDreamsCheat-vX.X.X.zip`).
3. Extract the contents directly into your Steam game directory:
   * **Default Path:** `Steam/steamapps/common/Hololive Dreams/` (the folder containing the main game executable).
4. Launch the game via Steam normally.

---

## Features

* **Auto-Play (Rhythm Bot)**  
  Automatically hits incoming notes with frame-perfect timing for flawless combos.

* **Movement Speed Modifier**  
  Adjust character traversal speed across all maps and zones to save travel time.

---

## Controls

* Press `Insert` (`Ins`) to toggle the in-game menu.
